# 示例说明

这个仓库目前附带一套公开示例：

- `stage-a-sample/`：一套通过 validator 的 `ecl pre` 初始化工作区

## 这份示例展示了什么

- 一个 normalized `case.json`
- 当前 schema 下完整的 markdown bundle 结构
- 自动生成的 OpenSpec 投影视图
- 为公开发布做过脱敏的占位绝对路径

## 这份示例没有宣称什么

这只是一个 Stage A 已初始化的工作区，不是一份已经完全收敛到 code-ready 的 case。

如果你想得到真正的 code-ready bundle，需要把完整 ECL 流程走完，完成 A-H 和 J，再进入 `plan` 与 `/code`。
