# Examples

This repository ships one public example:

- `stage-a-sample/`: a validator-passing workspace created by `ecl pre`

## What The Sample Shows

- a normalized `case.json`
- the full markdown bundle shape for the current schema
- generated OpenSpec projections
- placeholder-safe absolute paths for publication

## What The Sample Does Not Claim

The sample is a Stage A initialized workspace, not a fully converged code-ready case. It is designed to show the current repository structure safely and truthfully.

If you want a code-ready bundle, run the full ECL process on a real target repo and complete Stages A-H and J before invoking `plan` and `/code`.
